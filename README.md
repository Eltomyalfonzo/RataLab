# Rata32
# ¿Qué es Rata32?
Es un robot resuelve laberitos basados en la placa de desarrollo ESP32.
El robot esta en su fase beta y tiene un firmwar dedicado a la imbestigacion de metodos de resolucion de laberitos.
La ide del proyecto, es mejorar el diseño para que sea mas robusto y confiable.
El firmware que esta adjuntado aqui, permite calibrar el robot para su correcto funcionamiento dependiendo de las condiciones de la pista y del robot.
#Firmware 
El firmware recomendado es el de la carpeta robot_laberinto.
El Firmware_V1_Web.cpp es un fimware no modularizado y poco estable con problemas de conectividad y estabilidad en la utilizacion de el FreeRTOS.
